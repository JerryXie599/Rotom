- 宿主机只许带代理做两件事:出口预检、单次轻量判活(`curl -x http://127.0.0.1:18787 ...`),成规模动作不进宿主
- Python:`requests.get(..., proxies={'http':'http://host.orb.internal:18787','https':'http://host.orb.internal:18787'}, trust_env=False)`
- **判读坑**(出口侧失真,误判=白干):
  - 502 且响应带 `Proxy-Connection` = 代理链自答(目标未必死)→ 换原生 CONNECT 读 banner 复核
  - 目标全族域 TLS `unexpected eof` 而同出口访问第三方 200 = **出口 IP 被目标平台拉黑** → 立即换出口实例,别硬打
  - 经代理的端口扫描一律假阳性(死端口也回 OPEN):只认 HTTP 层,`curl -x <代理> http://IP:端口/`,502=关、其它状态码=开
  - "死域名"复活但内容是停放/钓鱼模板 = 出口侧 DNS 劫持,必须 DoH 双源复核
  - 起了无头 chromium/CDP 用完即杀(残留进程会拖垮整机);**少留痕**:UA/指纹常态化、不碰后台日志能不碰就不碰、探针/探针账号用唯一标记并在黑板登记
