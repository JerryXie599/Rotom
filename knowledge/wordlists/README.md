# 字典库(离线,agent 随取随用)

现场**无外网**,公开字典拿不到,所以常用字典落盘在这里。

## 口径(重要,别越线)

> **只收录公开可知的弱口令/默认口令标准内容 —— 不含任何题号绑定的信息、不含任何目标的具体答案。**
> 字典是"通用装备",它命中与否取决于目标的配置;把某一轮某个目标的答案写进字典里,那是夹带,不是准备。

配套纪律:生成器只按**形态**产候选(产品词×年份),不按"上次哪条中了"回填。

## 目录

| 路径 | 内容 |
|---|---|
| `系统与通用弱口令_base.txt` | 通用高频序 + 运维习惯口令,凭据墙第一张必过的表 |
| `vendor-passwords/*.txt` | 按厂商切的定向表(泛微/国产OA/网络设备/安防/运维中间件) |
| `usernames.txt` | 用户名面(与口令表配套,两个维度都要铺) |
| `vendor-vocab.txt` | 厂商 → 产品词根表,喂生成器用 |

`vendor-passwords/` 里的表是**人写人审的种子**,年份形态只放了几个示例 ——
完整的"产品词×年份"族**不要靠枚举**,用生成器现场产:

```bash
python3 tools/gen_product_year.py --vendor 泛微 --years 2023,2024,2025
python3 tools/gen_product_year.py seeyon landray tongda --compact
```

## 组表与顺序(限速环境下,顺序就是策略)

```bash
# 把三张面拼成一张有序表;本目标已观测到的凭据用 --reuse 传进去
python3 tools/dict_prep.py --vendor 泛微 --reuse observed_creds.txt --out pw_ordered.txt
```

顺序固定为 **① 厂商定向(含生成的产品词×年份族) → ② 本目标已观测凭据(复用值) → ③ 通用高频序**。
理由见 `knowledge/playbooks/credential-wall.md`:认证服务常有硬限速
(有些目标实测 `>1 并发即 RESET`、单发 2.5~3 秒,有效速率不到 1 发/秒),
一张几千条的字典**永远跑不完** —— 只有把最可能的排最前面才有意义。

`dict_prep.py` 按这个顺序出表,**不接受重排参数**;确实要改顺序就先改
`vendor-vocab.txt`/表文件,不要在执行时临时打乱。

## 复用值(footgun)

内网横向里"同一个口令跨系统复用"是最高频的现实。每拿到一个凭据,立刻记进
工作目录的 `observed_creds.txt`,下一跳先用它 —— 这是投入产出比最高的一类候选。
