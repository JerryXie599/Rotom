# vendor-vocab.txt —— 厂商/产品 → 词根表(喂 tools/gen_product_year.py 生成"产品词×年份"候选族)
#
# 口径:只收录**公开可知的厂商名与产品名**(官网/公告/安装包里的名字),
#       不含任何题号绑定的信息,也不含具体口令 —— 口令由生成器按形态现场算。
# 用法:指纹识别出厂商后,取对应行的产品词喂生成器:
#   python3 tools/gen_product_year.py weaver ecology            # 指定词根
#   python3 tools/gen_product_year.py --vendor 泛微              # 按厂商名取词根
#   python3 tools/gen_product_year.py weaver --years 2022-2025   # 指定年份区间
#
# 为什么需要它:国产 OA/设备的口令设计有很强的"产品词+年份"习惯
#   (weaver@2023 / Ecology@2024 / Huawei@2023 这类)。这类形态**用通用泄露字典永远覆盖不到**,
#   必须按指纹现场生成 —— 生成成本几乎为零,漏了却要拿限速通道的每一发去补。
