# 卡:会话 / 验证码 / 签名凭据(用语义取巧,不用暴力)

**适用**:登录被验证码挡住、JWT 可伪造、签名 cookie 可解、session 可预测。

| 场景 | 思路 |
|---|---|
| 验证码 | **别 OCR**:① 用已到手的 SSRF/LFI 读服务端会话文件(`/var/lib/php/sessions/sess_<PHPSESSID>`、`/tmp/sess_*`)拿明文;② 验证码与答案同响应(JS/接口返回);③ 验证码可复用/不刷新;④ 换会话不换码 |
| JWT | `alg:none`;`kid` 注入(路径/命令/SQL);弱 HMAC 密钥(用 `hashcat -m 16500` 小字典,别大字典);`jku`/`x5u` 指向自己(见云侧卡);claim 越权(`role`/`sub`/`uid`) |
| 签名 cookie | 找签名前的原文(base64 解开看结构);找密钥泄露(源码/配置/机器人);篡改后重签 |
| session | 预测(时间戳/自增/弱随机)、固定(session fixation)、可跨用户复用 |
| 认证绕过 | 数组/重复参数污染(`user=a&user=b`)、类型混淆(JSON `true`/`0`)、路径大小写与 `;` 截断、`X-Forwarded-*` 伪造来源 |

## 纪律
- 弱口令/弱密钥爆破:小字典 + 限速(线程 ≤10、加延时),先试厂商默认口令表;
- 涉及会话伪造时,只用**最小验证**(能证明越权即止),不要批量拉取他人数据。
