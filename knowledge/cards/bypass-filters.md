# 卡:payload 被拦时的绕过矩阵

**适用**:回显出现"危险字符/被过滤/403/WAF",或 payload 送不进去。
(详细分类见 `knowledge/web.md` 的 WAF 一节;这里是**速查矩阵**,按顺序试。)

| 手法 | 例子 |
|---|---|
| 大小写 / **双写** | `SeLeCt`、`seleselectct`、`<sc<script>ript>` |
| 编码叠加(**双重编码**/多重编码) | URL 编码(单/双/三重:`%252e`)、Unicode(`\u003c`)、HTML 实体、**UTF-16/UTF-7**(`<?xml version="1.0" encoding="UTF-16"?>`) |
| 内联注释 / 换行 | `/**/union/**/select`、`%0a`、`%0d%0a`、`--` 后换行 |
| 空白替代 | `+`、`%09`、`%0b`、`/**/`、`$IFS`(命令注入) |
| 等价函数 / 语法 | `||` 代替 `or`、`and`→`&&`、`sleep()`→`benchmark()` |
| 参数污染 | 同名参数多份(`?a=1&a=2`)、`?a[]=`、JSON vs 表单切换 |
| 协议/入口切换 | 换 Content-Type、换方法(GET→POST→PUT)、换端点(同逻辑的另一条路由) |
| 编码层错位 | 双重解码点:先 `%2e` 再 `..`;路径穿越 `..%2f`、`%252e%252e/` |

**判定诊断法**:同一 payload 只改一个变量,记录哪一步开始被拦(网络层/WAF/应用层);
如果"原样重发"三次都一样,就说明**这不是变体问题**,换攻击面或换入口。
